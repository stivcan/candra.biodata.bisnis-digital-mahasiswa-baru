Mengenal Lebih Dekat

Halo semuanya! Perkenalkan, nama lengkapku Stiven Candra Winata. Biasa dipanggil Candra. Saya lahir di Ngawi dan besar di Magetan, dan saat ini saya menjadi mahasiswa Kampus Institut Teknologi Dan Bisnis Tuban jurusan Bisnis Digital.

Saya suka belajar teknologi karena keingintahuan yang tinggi tentang dunia digital. Teknologi dapat memudahkan dalam banyak hal termasuk dunia bisnis.

Website ini saya buat sendiri pakai HTML, CSS, dan JavaScript walau menggunakan AI dengan saya desain di Canva. Dengan AI saya belajar bahwa teknologi dapat membantu dalam banyak hal tapi kita jangan sampai malas untuk tetap belajar. AI memang merubah banyak hal di sekitar kita tapi website ini tetap saya ubah dalam banyak hal dan belajar di setiap kodenya untuk memahami bagaimana cara kerja teknologi bekerja.
